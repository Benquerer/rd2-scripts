> G0/2 -> Conecta com o RX com maior X

### Router 1
```ios
! --- Basic Configuration ---  
enable
conf t
hostname RouterR1_G1
no ip domain-lookup
enable secret class
banner motd # ! Acesso restrito, continue apenas se autorizado ! #
! --- Console Port  --- 
line console 0
 password class
 login
 exit
! --- Virtual Terminal Lines ---
line vty 0 4
 password class
 login
 exit
! --- Interfaces --- 
ipv6 unicast-routing
int g0/0
 description R1 - Rede Interna
 ipv6 address 2001:DB8:2526:1110::1/64
 no shut
 exit
int g0/1
 description R1 - Rede p/ R2
 ipv6 address 2001:DB8:2526:1113::1/64
 no shut
 exit
int g0/2
 description R1 - Rede p/ R3
 ipv6 address 2001:DB8:2526:1115::1/64
 no shut
 exit
int s0/0/0
 description R1 - Rede Ext
 ipv6 address 2001:DB8:2526:1116::1/64
 no shut
 exit
! --- RIPng Configuration ---
ipv6 router rip CISCO
 default-information originate
 exit
int g0/0
 ipv6 rip CISCO enable
 exit
int g0/1
 ipv6 rip CISCO enable
 exit
int g0/2
 ipv6 rip CISCO enable
 exit
int s0/0/0
 ipv6 rip CISCO enable
 exit
! --- Default Route ---
ipv6 route ::/0 2001:DB8:2526:1116::2
! --- Save Configuration --- 
end
copy running-config startup-config
```
