#### Conexão das interfaces:

> G0/0 -> SwitchCentral (VLAN4)
> G0/1 -> Conecta com o RX com menor X
> G0/2 -> Conecta com o RX com maior X

---

### Router 1

```ios
enable
conf t
hostname RouterR1_G4
no ip domain-lookup
enable secret class
banner motd # ! Acesso restrito, continue apenas se autorizado ! #
line console 0
 password class
 login
 exit
line vty 0 4
 password class
 login
 exit

int Loopback0
 description R1 - Rede Interna (Loopback)
 ip address 192.168.43.193 255.255.255.224
 no shut
 exit

int g0/0
 description R1 - Rede Ext (VLAN4)
 ip address 10.0.0.14 255.255.255.252
 no shut
 exit

int g0/1
 description R1 - Rede p/ R2
 ip address 192.168.43.225 255.255.255.252
 no shut
 exit

int g0/2
 description R1 - Rede p/ R3
 ip address 192.168.43.229 255.255.255.252
 no shut
 exit

router rip
version 2
no auto-summary
passive-interface Loopback0
network 192.168.43.192
network 192.168.43.224
network 192.168.43.228
network 10.0.0.0
exit

end
copy running-config startup-config
```
