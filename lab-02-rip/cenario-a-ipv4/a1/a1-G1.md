#### Conexão das interfaces:

> G0/0 -> Rede Interna

> G0/1 -> Conecta com o RX com menor X

> G0/2 -> Conecta com o RX com maior X
--- 

### Router 1
```ios
! --- Basic Configuration ---  
enable
conf t
hostname RouterR1_G1
no ip domain-lookup
enable secret class
banner motd # ! Acesso restrito, continue apenas se autorizado ! #

! --- Console Port  --- 
line console 0
password class
login
exit

! --- Virtual Terminal Lines ---
line vty 0 4
password class
login
exit

! --- Interfaces --- 
int g0/0
description R1 - Rede Interna
ip address 192.168.11.193 255.255.255.224
no shut
exit

int g0/1
description R1 - Rede p/ R2
ip address 192.168.11.225 255.255.255.252
no shut
exit

int g0/2
description R1 - Rede p/ R3
ip address 192.168.11.229 255.255.255.252
no shut
exit

!  REDE EXTERNA - A CONFIGURAR
! int g0/3
! description R1 - Rede Ext
! ip address XXXXX YY
! no shut
! exit

! --- RIPv2 Configuration ---
router rip
version 2
no auto-summary
passive-interface GigabitEthernet0/0
network 192.168.11.192
network 192.168.11.224
network 192.168.11.228
default-information originate
exit

! --- Save Configuration --- 
end
copy running-config startup-config
```
