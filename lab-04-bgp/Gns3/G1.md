## Tarefa 2 — Configurações Básicas

### R1

```ios
configure terminal
hostname R1
no ip domain-lookup
enable secret class
banner motd #Acesso autorizado apenas.#
line console 0
 password class
 login
line vty 0 15
 password class
 login
service password-encryption

interface Loopback0
 ip address 1.1.1.1 255.255.255.255

interface G0/0
 ip address 172.100.100.1 255.255.255.0
 no shutdown

interface G0/1
 ip address 1.1.13.1 255.255.255.252
 no shutdown
exit
router ospf 1
router-id 1.1.1.1
auto-cost reference-bandwidth 1000
network 1.1.1.1 0.0.0.0 area 0
network 1.1.13.0 0.0.0.3 area 0
end
copy running-config startup-config
```
